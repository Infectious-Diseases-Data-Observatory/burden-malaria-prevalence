> **Note, 18 September 2026:** the Snow prevalence comparison (former plan §3.4.2) was removed from the plan and its code (`R_cbh/snow/`, `R_dhs/51_snow_polygon_prevalence.R`) moved to [`archive/2026-09-18-snow-comparison/`](../archive/2026-09-18-snow-comparison/README.md). Rows below that cite those scripts describe the audit as of 15 September and are retained unchanged. `results/cbh/map_snow_gamma2_v1/` still holds the original primary `map_full` fits.

The **saved primary MAP gamma=2 models agree with the declared model and prepared data**. The pipeline as a whole does **not yet implement every component of the plan**. At the audit baseline, the largest gaps were the inherited regional MAP extraction, primary-compatible sensitivity fits, survey/design and imputation uncertainty, and a standalone primary fitting/reporting workflow. The follow-up below records the new primary-only rerun.

This review checks code behaviour against the plan; agreement with the plan is not evidence that the adjustment set identifies a causal effect. No DHS model or HIV imputation model was refitted, no source was downloaded, and no existing scientific estimates or data were changed. Synthetic model tests did fit small simulated models. The saved primary dataset and model frames were read locally for verification; only aggregates were exported.

## Follow-up: primary-only rerun

After this audit, the user requested a complete primary analysis rerun without data setup. [R_cbh/primary/](../R_cbh/primary/README.md) now provides that entry point: `Rscript run_all.R --primary`. Seven MAP gamma=2 models were freshly fitted directly from the prepared sample with the preserved reference knots. New effects, country mortality for 2005/2015/2024, fitted-outcome checks, primary-only figures, inclusion flow and the results index are in [primary_map_gamma2_v1](../results/cbh/primary_map_gamma2_v1/REPORT.md). All seven passed the numerical checks and reproduced the preceding results to numerical precision. The preceding data, models and comparison outputs remain unchanged.

This addresses the standalone primary fitter/reporting gap identified below. The component matrix remains the record of the audit baseline: its references to that gap are historical. The inherited regional MAP extraction, planned gamma=2 sensitivities, survey/design and imputation uncertainty remain unresolved. The new in-sample grouped outcome checks do not replace influence analysis or held-out validation. National burden still consumes explicit baseline columns from the existing national input tables; no input preparation was rerun.

## Findings requiring follow-up

### F01 — Regional MAP extraction needs a versioned replacement before a new primary build

The exact annual join in CBH is correct; the input extractor is not yet consistent with all the intended upstream requirements. `R_dhs/41_extract_map_window_years.R` filters the registry to surveys found in the survey-year MAP table. Script 02 only emits regions with usable survey-year PfPR, so the boundary-definition snapshot also carries exposure selection. Both scripts weight by resampled population density without cell area. In script 41, `w` is masked to the last selected raster, and that denominator is used for all years: changing no-data coverage can affect earlier-year means. Script 02/41 caches are reused by filename without checking raster, population, boundary or code hashes.

Build boundary definitions independently of survey-year exposure, enumerate required years from eligible band entries, calculate valid-population denominators for each year, retain coverage flags and hash all extraction inputs. Compare keyed old/new regional means and sample composition before refitting. These issues could change the estimates; they were not silently corrected during an archival audit.

### F02 — Do not confuse historical commands with current primary models

`analysis/01_fit_complete_case.R` without `--prepare-only` still fits the old joint model. `sensitivity/01_fit.R` still uses gamma=1; its geographic and period models are joint, not separate-age. `burden/settings.R` defaults to the old separate gamma=1 family. Script 51 defaults to five-year Snow draws rather than the specified annual CSV series. All are retained with explicit documentation because they have live dependencies or supplementary roles. The new root runner does not call them automatically.

The selected primary objects are **only** `map_full` in `results/cbh/map_snow_gamma2_v1/fit_manifest.csv`. No fallback based on which cached fit happens to exist is appropriate. A fresh primary fit currently needs historical reference frames/knots; the burden calculation needs previously generated national input tables. This dependency is why some older CBH code is not redundant yet.

### F03 — Numerical agreement is not complete statistical validation

The new verifier checks every primary frame column and exact model hashes, not merely matching sample sizes. Positive Hessians do not settle basis adequacy, confounding, influential countries or residual dependence. The saved HIV full-parameter audit reports maximum R-hat 1.0042 and minimum ESS 900.7; the main summary reports no divergences or tree-depth hits. The operational HIV diagnostic gate checks a selected parameter subset, so full latent/censored-parameter diagnostics should become an automatic gate too. HIV validation leaves adolescent observations available while withholding child series; a mortality validation fold would need its own training-fold preprocessing policy.

### F04 — Required sensitivity analyses remain real work

The plan explicitly marks many checks as future work. Archiving an older NB/Poisson or joint-model sensitivity does not remove a completed primary-compatible analysis: those methods target different records, outcomes or nuisance structures. Implement the required gamma2 joint and separate-age geography/period fits first, then design/dependence and HIV uncertainty, followed by timing, age coding, adjustment and dose-response checks. Preserve the current fixed-imputation unweighted reference.

### F05 — Reporting still needs separation and completion

The existing comparison code correctly computes 40→20 HRs and retains signed primary burden estimates, but dedicated MAP-only main figures are missing. `analysis/02_plot_trial.R` computes curves from the old joint fit; `analysis/04_propagate_incidence.R` combines fitting and plotting; `snow/10_compare_burden_gamma2.R` combines effects with plotting. `snow/09_report_map_comparison_gamma2.R` also rewrites `model_formula.txt` merely to trim whitespace. Separate these responsibilities when consolidating reporting, and stop editing fit-stage artifacts from plotting stages.

The historical `burden/03_compare_ihme.R` asserts positive country estimates and uses log axes, unsuitable for a future sensitivity producing zero/negative country totals. Current gamma2 burden code retains signed age and country estimates; use a signed-compatible plotting scale in its dedicated replacement. Do not port that positivity assertion into primary reporting.

### F06 — Retained input bridges contain surplus branches

`R/00_utils.R`, `R/01_fetch_data.R`, `R/03_component3_rdt_microscopy.R`, `R/11_malaria_deaths_timeseries.R` and `R_dhs/00_config.R`, `01`, `02`, `02b`, `02c`, `03`, `41`, `51` remain because they provide unique helpers or snapshot/comparator inputs. In particular, WB health-spending/governance preparation is still embedded in script03; the legacy national MAP table read by burden preparation is produced by R/11. Optional measured-prevalence checks require R/03.

Their old model helpers, nearest-year joins, generic imputation, migration mode and outcome-dependent panel processing are **not primary CBH logic**. Extract their input-only functions with explicit local/retrieval stages before archiving the remainder. Merely leaving a cached CSV in this workspace is not a replacement producer.
